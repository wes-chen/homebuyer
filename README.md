# homebuyer

A homebuyer education program: weekly short lessons taking a complete beginner
from zero to a personal buy-box for a single-family home in the South Bay /
Peninsula.

- `syllabus.md` — the 14-lesson curriculum (money → search → process)
- `lessons/` — one file per delivered lesson

One lesson per week. General education, not personalized financial, tax, or
legal advice.
